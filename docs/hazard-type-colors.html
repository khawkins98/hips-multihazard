HIPs Hazard Type Colors

Reference palette for the 8 UNDRR Hazard Information Profile types, plus the unmapped fallback. Source of truth: src/data/hazard-types.js. Each type has a solid (matches the UNDRR-ISC 2025 Update print style — full-bleed bars with white text), a border (saturated, used for outlines/strokes on screen), and a bg (tinted, used for fills on light surfaces).
